# S7 recovery after host restart (2026-11-24)

**What happened.** The host restarted while wave `s7w1009` was running. That wave held phase A of seed 1009 (152 runs) and the 15 phase-B runs of seed 1008.
- The last output was written at 05:01:27 EET.
- The executor's last log line was 04:44:34, the start of the wave.
- When the host came back at 08:37, no S7 processes were running.

## 2. Recovery procedure

The procedure is `results/s7/recovery/s7_recover.py`. It is engineering only: design, arguments, seeds, rules and analysis are unchanged.

1. Back up `state.json` and `derived.jsonl` (`results/s7/recovery/*.pre-recovery.*`).
2. Read the planned runs of s7w1009 from `plan.jsonl`, which was written before the wave started.
   - Check that phase A of seed 1009, regenerated by the frozen executor, equals the plan.
3. Accept a run of the interrupted batch only if all of the following hold:
   - its manifest exists, with status completed and rc 0;
   - commit 18e8985, with a clean tree;
   - the frozen binary sha256;
   - argv identical to the frozen `args()`;
   - every listed output has the recorded size and the recorded sha256.

   Result: **156/156 accepted**.
4. Write the provenance for the interrupted batch to `results/s7/s7w1009/20261124T024434Z/`: `manifests.jsonl`, `SHA256SUMS`, and `BATCH.json` marked *interrupted*.
   - Partial files of the 7 interrupted runs stay in the raw directory as evidence. The index never points at them.
5. Simulate only the 11 missing runs, in continuation batch `s7w1009c`, with the unchanged `run_batch` and a single-retry policy. All 11 are seed-1008 phase-B runs:
   - 8 at D1 + Δ3;
   - 3 at C3.
6. Mark s7w1009 as done. Then hand control back to the unchanged `s7_run.py run --jobs 7`, which resumes at seed 1010. No completed run is re-simulated.

## 3. Effect on the study

There is none on the design or the statistics.
- The 11 reruns use the frozen arguments and seeds.
- ns-3 runs are deterministic for a given argv and seed, so a rerun of an interrupted run is the same experiment.
- The only lasting trace is that `s7w1009` and `s7w1009c` are two batch directories instead of one.
