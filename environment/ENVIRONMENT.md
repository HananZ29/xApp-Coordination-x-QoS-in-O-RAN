## ns-3 build configuration

```
cd ~/ns-3.42
./ns3 configure --build-profile=default --enable-examples --enable-tests
./ns3 build
```

Resulting flags: `CMAKE_BUILD_TYPE=default`, `NS3_ASSERT=ON`, `NS3_LOG=ON`,
`NS3_SQLITE=ON`, `NS3_EXAMPLES=ON`, `NS3_TESTS=ON`, `NS3_WARNINGS_AS_ERRORS=OFF`,
Python bindings off, contributed modules: `ns3-oran`.

## Building and running this project

`scratch/xapp-coord/CMakeLists.txt` lists every C++ source explicitly (ns-3 does not
glob nested scratch folders). The target is `scratch_xapp-coord_xapp-coord`; the
executable is `build/scratch/xapp-coord/ns3.42-xapp-coord-default`.

```
./ns3 build xapp-coord
./ns3 run "xapp-coord --help"
```

Batch scripts call the executable directly with `LD_LIBRARY_PATH=~/ns-3.42/build/lib`
so a run never triggers a reconfigure.

## Reproducibility checks

- `scripts/validation/s0-regression.sh <binary> <out_dir>`: runs the archived cases
  (`configs/baseline/s0-regression-cases.txt`).
- `scripts/validation/compare_runs.py <cases> <A> <B>`: byte-level comparison (exit 0 only
  if every comparable file is identical).
- `scripts/validation/run-ns3-tests.sh <out_dir>`: relevant ns-3 and ns3-oran test suites
  plus ns3-oran reference examples.
